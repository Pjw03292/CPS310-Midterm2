Write a Python function named step(agents, events) for a turn-based zombie simulator. agents maps character names to states, and events is a list of (actor, event) pairs. A human can wait, move, or receive a bite and become infected. An infected character can wait or turn into a zombie. A zombie can wait or move. Each character can receive at most one event per tick. Raise ValueError for unknown actors, illegal events, or multiple events for the same actor. Return a new dictionary and leave the input unchanged. Return only the Python code.
